# Архитектура

```
src/
  main.js                 игровой цикл, связывание модулей, обработка действий
  config.js               пресеты качества, параметры по умолчанию, начальные условия
  physics/                ── физика (без зависимостей от браузера, тестируется в Node)
    units.js              константы, переход геометрические единицы ↔ СИ, форматирование
    kerr.js               метрика Керра–Шилда, производные, Кристоффели, горизонты,
                          ISCO, фотонные орбиты, наблюдатели (статический, ZAMO, «дождевой»)
    geodesic.js           мировая линия корабля: геодезическая + тяга, Ферми–Уокер, RK4
    tidal.js              тензор Римана, приливный тензор, собственные значения, Кречман
    photon.js             JS-копия GPU-трассировщика (для тестов и расчётов на CPU)
    disk.js               диск Новикова–Торна (Пейдж–Торн), профиль температуры
    spectrum.js           Планк, CIE 1931, таблицы цвета/ИК/болометрии для шейдера
  render/                 ── рендеринг (Three.js, WebGL2, собственные GLSL-шейдеры)
    pipeline.js           конвейер: трассировка → накопление → экспозиция → bloom →
                          тонмаппинг → сцена кабины → вывод; динамическое разрешение
    shaders/raytrace.js   трассировка лучей + перенос излучения в объёмном диске
    shaders/sky.js        генерация кубической карты неба
    shaders/post.js       накопление, яркость, экспозиция, bloom, тонмаппинг, вывод
    shaders/common.js     вершинный шейдер, шум, доступ к спектральной таблице
  sim/                    ── симуляция
    simulation.js         состояние корабля, тяга, ускорение времени, события,
                          приборные величины; свободная камера-зонд
    predictor.js          баллистический прогноз (по частям в каждом кадре)
    frames.js             тетрады наблюдателей, ковекторы для шейдера
  ship/                   ── корабль
    structure.js          нагрузки, отказы систем, экипаж, разрушение
    cockpit.js            процедурная кабина (стекло, стойки, панели, кресло, ручки)
    exterior.js           внешняя модель, факелы двигателей, деформация, разлёт
  camera/cameraRig.js     камеры: кабина (обзор головой с инерцией), внешняя, свободная
  input/                  клавиатура/мышь (pointer lock) и сенсорные джойстики
  ui/                     HUD, мониторы кабины (canvas), научная панель, экраны
  audio/audio.js          процедурный звук кабины (WebAudio), радиосвязь (Speech API)
tests/                    физические тесты (node --test)
tools/view.html|js        статический вид по параметрам адресной строки (отладка)
tools/gpu-test.mjs        сквозной тест шейдера в headless Chromium
docs/                     документация
econometrics/             прежнее приложение репозитория (не связано с симулятором)
```

## Поток данных за кадр

1. `Input.poll()` → тяга, команды ориентации, обзор, действия.
2. `Simulation.update()` интегрирует мировую линию корабля на
   `dt·warp` собственного времени (подшаги RK4), вращает тетраду, фиксирует
   события (горизонт, отказы, разрушение, граница модели), считает приборные
   величины и приливный тензор, продвигает баллистический прогноз.
3. `CameraRig.update()` — направление взгляда (в осях корабля).
4. Позиция и тетрада камеры (корабля или зонда) → ковекторы `U, E₁, E₂, E₃`
   → униформы шейдера.
5. `RenderPipeline.render()`:
   трассировка в HDR-буфер (динамическое разрешение, предэкспозиция) →
   накопление кадров при неподвижной камере (субпиксельный сдвиг Халтона) →
   лог-яркость в mip-цепочку → адаптация экспозиции (1×1 текстура, на GPU) →
   bloom → тонмаппинг/ложные цвета → сцена Three.js (кабина/корабль) поверх
   изображения с буфером глубины и MSAA → sRGB на экран. Каждые 8 кадров
   снимок 4×4 изображения задаёт цвет и направление внешнего освещения кабины.
6. HUD, мониторы кабины, звук.

## Производительность

* Пресеты Low / Medium / High / Ultra меняют число шагов и шаг интегратора,
  октавы шума, разрешение кубической карты неба, MSAA и границы
  динамического разрешения; физическая модель одна.
* Динамическое разрешение подстраивает масштаб буфера трассировки под ~60 FPS.
* Накопление кадров (temporal accumulation) включается, когда камера и
  изображение неподвижны (например, на паузе), и даёт сглаживание и
  прогрессивное уточнение.
* Шаг интегратора адаптивен: крупный вдали, мелкий у горизонта, у фотонной
  сферы и в диске; толщина диска «прощупывается» ограничителем шага, поэтому
  тонкий диск не пропускается.
