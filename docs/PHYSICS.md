# Физическая модель и приближения

Документ описывает, что именно считает симулятор, какими методами, и
перечисляет **все** приближения. Всё, что не перечислено как приближение,
является прямым следствием уравнений общей теории относительности (ОТО).

## 1. Единицы

Расчёты ведутся в геометрических единицах `G = c = M = 1`:
длина `GM/c²`, время `GM/c³`. Для Sgr A* (M = 4·10⁶ M☉):

| величина | значение |
|---|---|
| GM/c² | 5.91·10⁹ м |
| радиус Шварцшильда 2GM/c² | 1.18·10¹⁰ м ≈ 0.079 а.е. |
| GM/c³ | 19.7 с |

Масса входит только в переход к СИ (километры, секунды, перегрузки, приливы
в 1/с²) и в температуру диска. Геометрия изображения в единицах M от массы не
зависит. См. `src/physics/units.js`.

## 2. Метрика

Используется метрика Керра в декартовых координатах **Керра–Шилда**
(входящих), `src/physics/kerr.js`:

```
g_μν = η_μν + f l_μ l_ν,        g^μν = η^μν − f l^μ l^ν
f    = 2Mr³ / (r⁴ + a²z²)
l_μ  = (1, (rx + ay)/(r² + a²), (ry − ax)/(r² + a²), z/r)
r⁴ − (x² + y² + z² − a²) r² − a²z² = 0
```

`r` совпадает с радиальной координатой Бойера–Линдквиста. Координаты
регулярны на горизонте событий `r₊ = M + √(M² − a²)`, поэтому корабль и лучи
непрерывно переходят через него. При `a = 0` это метрика Шварцшильда во
входящих координатах Эддингтона–Финкельштейна. Производные метрики и символы
Кристоффеля вычисляются аналитически.

Режим **Шварцшильда** — `a = 0`; режим **Керра** — `0 < a ≤ 0.998`
(предел Торна для аккрецирующей ЧД). Увлечение инерциальных систем,
асимметрия тени, изменение фотонных орбит и ISCO возникают автоматически из
метрики, отдельно не «добавляются».

## 3. Трассировка лучей (изображение)

Файлы: `src/render/shaders/raytrace.js` (GLSL) и его точная копия на JS
`src/physics/photon.js` (используется в тестах).

Изотропные геодезические интегрируются в гамильтоновой форме:

```
H = ½ g^μν p_μ p_ν = ½ (η^μν p_μ p_ν − f s²),   s = −p_t + l·p
dx^i/dλ = p_i − f s l_i
dp_i/dλ = ½ s² ∂_i f + f s ∂_i (l·p)
dt/dλ   = −p_t + f s,              p_t = const
```

* Лучи идут **назад во времени** от камеры. Начальный ковектор
  `p = −u + n^a e_a` строится по тетраде камеры (4-скорость `u` и
  ортонормальная тройка `e_a` корабля, повёрнутая направлением взгляда), с
  нормировкой `p·u = 1`. Поэтому аберрация и доплеровский сдвиг от движения
  корабля учтены точно.
* Метод — Рунге–Кутта 4-го порядка. **Приближение:** шаг выбирается
  эвристически (пропорционален расстоянию до центра, уменьшается у горизонта
  и внутри диска), без контроля локальной ошибки. Точность проверена тестами
  (сохранение `H = 0` и константы Картера, размер тени).
* **Приближение:** число шагов ограничено пресетом качества (220–900).
  Лучи, совершающие очень много оборотов вблизи фотонной оболочки, обрываются
  и считаются тёмными — это влияет лишь на самые тонкие кольца высших порядков.
* **Критерий захвата.** Луч, прошлое которого прижимается к горизонту
  (`|r − r₊| < 0.2M` и `|dt/dλ| > 30 |dx/dλ|`), считается тёмным: в
  координатах Керра–Шилда такие лучи уходят к прошлому горизонту (область
  «белой дыры» вечного решения). **Приближение:** у реальной ЧД, возникшей при
  коллапсе, там была бы бесконечно покрасневшая поверхность звезды — её мы не
  моделируем.
* **Асимптотическое направление** луча берётся по направлению импульса `p_i`
  при `R ≥ max(80M, 2.2 r_диска, 1.02 R_камеры)`. В координатах Керра–Шилда
  входящая главная изотропная конгруэнция — прямые линии, поэтому ошибка
  убывает как `R⁻⁴`: при 80M — около 10⁻⁵ рад (проверено тестом).

## 4. Перенос излучения, цвет, смещение частот

Ключевой инвариант: `I_ν/ν³` сохраняется вдоль луча. Поэтому чёрное тело
температуры `T`, наблюдаемое с отношением частот `g = ν_набл/ν_изл`,
выглядит **точно** как чёрное тело температуры `g·T`. Одна подстановка
`T → g·T` даёт одновременно гравитационное красное смещение, эффект Доплера и
релятивистское усиление яркости (beaming).

* Для газа диска `g = 1/(p·u_газа)`, для звёзд `g = 1/p_t` (свет от
  неподвижных источников на бесконечности).
* Вдоль луча в объёме диска решается уравнение переноса:
  `dI = T·(1 − e^{−dτ})·B(g·T_газа)`, `T ← T·e^{−dτ}`,
  `dτ = κρ·ds`, где `ds = (p·u_газа)·dλ` — длина пути в системе газа.
* Цвет: интеграл функции Планка с функциями сложения цветов CIE 1931
  (**приближение:** аналитическая многолепестковая аппроксимация Wyman, Sloan
  & Shirley 2013) → XYZ → линейный sRGB. **Приближение:** хроматичность
  холоднее ~1900 К выходит за гамут sRGB и обрезается.
* Таблица `цвет(T)` (1024 значения, 100 К…3·10⁹ К) считается на CPU при
  запуске (`src/physics/spectrum.js`), яркость нормирована на яркость
  поверхности Солнца.
* **Диапазоны:** видимый (CIE); условный ИК — интеграл `B_λ` по 1–5 мкм,
  отображается ложными цветами; научный — цвет показывает `log₂ g`
  (синий — синее смещение, красный — красное), яркость — болометрическая.

## 5. Аккреционный диск

`src/physics/disk.js`, объём — в шейдере.

* Эффективная температура — **тонкий диск Новикова–Торна**, поток с
  релятивистской поправкой Пейджа–Торна (замкнутая формула; тест сверяет её с
  численным интегралом законов сохранения энергии и момента):
  `F = 3GMṀ/(8πr³)·Q(r, a)`, `T_eff = (F/σ)^{1/4}`.
* Темп аккреции задаётся долей эддингтоновского: `Ṁ = ṁ·L_Edd/(η c²)`,
  `η = 1 − E_isco`. Цвет диска **вычисляется** из `M`, `Ṁ`, `a` и смещения
  частот. Пример для 4·10⁶ M☉, a = 0: `ṁ = 10⁻⁷ → T_max ≈ 5000 К`
  (оранжево-жёлтый), `ṁ = 10⁻³ → 5·10⁴ К` (голубовато-белый).
* Внутренний край — ISCO (нулевой момент сил), внешний — параметр.
* **Приближения объёмной структуры:**
  * плотность гауссова по высоте, `H/r = const`;
  * вертикальная температура — серая атмосфера Эддингтона
    `T(τ) = T_eff·[¾(τ + ⅔)]^{1/4}`;
  * турбулентность — процедурный логнормальный шум плотности (размер
    неоднородностей ∝ r) плюс флуктуации температуры ±12%·(турбулентность);
    это **не** МГД-моделирование;
  * узор сносится кеплеровским вращением со сдвигом; чтобы он не наматывался
    бесконечно, используются два перекрывающихся цикла по 2 орбитальных
    периода с плавным переходом;
  * время излучения учитывает задержку света вдоль луча (`dt/dλ`);
  * 4-скорость газа — круговое вращение с кеплеровской `Ω(r)` на
    сфероидальных оболочках (вне плоскости — тоже приближение);
  * нет излучения изнутри ISCO, нет переоблучения диска собственным светом,
    рассеяния, поляризации и цветовой поправки Комптона;
  * диск лежит в экваториальной плоскости ЧД (выравнивание Бардина–Петтерсона).
* **Замечание о Sgr A*:** реальный поток вокруг Sgr A* — горячий
  оптически тонкий (RIAF), излучающий в основном в радио- и ИК-диапазонах
  (синхротрон). Тонкий диск — стандартная модель для более активных ядер;
  «Sgr A*» в симуляторе — это масса и, по желанию, низкий темп аккреции.

## 6. Звёздное небо

`src/render/shaders/sky.js`. **Приближение:** небо процедурное (не каталог):
звёзды четырёх слоёв со степенным распределением звёздных величин
(`N(<m) ∝ 10^{0.5m}`) и реалистичной долей спектральных классов, плюс
диффузное свечение диска Галактики с пылевыми прожилками. Калибровка яркости —
через звёздную величину и температуру относительно Солнца.

Кубическая карта хранит `(ε, ε·log T)`, где `ε` — фактор разбавления
чёрного тела; обе величины линейны и корректно усредняются в mip-уровнях.
**Приближения:** звёзды — гауссовы пятна размером ~1 тексель; в смешанных
текселях берётся средневзвешенная `log T`. Линзированные звёзды сохраняют
поверхностную яркость (теорема Лиувилля), фильтрация по mip-уровням
приближённо усредняет изображение по площади пикселя.

## 7. Экспозиция и восприятие

Эти элементы — **модели восприятия, а не физика ЧД**:

* HDR: изображение рендерится в линейной яркости (half float) с
  предэкспозицией; экспозиция адаптируется на GPU (τ ≈ 0.45 с).
* Режим «Глаз» — замер по светлым участкам (как дневное зрение рядом с ярким
  источником). Поверхностная яркость диска при T ~ 5000 К сравнима с
  поверхностью Солнца, а звёзд — в ~10¹⁰ раз меньше, поэтому **рядом с ярким
  диском звёзды физически не видны** — это не ошибка.
* Режим «По фону» — лог-среднее (видны звёзды, диск пересвечен).
* Ореол (bloom) — модель рассеяния света в глазу/оптике; яркость, питающая
  ореол, ограничена (упрощение).
* Тональная компрессия ACES (аппроксимация Narkowicz), виньетирование.
* Координатная сетка неба — наглядное наложение, отключено по умолчанию.

## 8. Движение корабля

`src/physics/geodesic.js`, `src/sim/simulation.js`.

```
dx^μ/dτ   = u^μ
du^μ/dτ   = −Γ^μ_αβ u^α u^β + A^μ,          A^μ = Σ T_b e_b^μ
de_b^μ/dτ = −Γ^μ_αβ u^α e_b^β + T_b u^μ      (перенос Ферми–Уокера)
```

* Тяга — собственное ускорение в осях корабля. Без тяги — точная
  геодезическая; тетрада переносится параллельно, т.е. это идеальные
  гироскопы (геодезическая прецессия и эффект Лензе–Тирринга — проверено
  тестом прецессии `2π(1 − √(1 − 3M/r))` за оборот).
* RK4 с шагом `≈ 0.004·r^{3/2}` (доля локального динамического времени),
  после каждого шага — переортонормировка тетрады по Граму–Шмидту.
* Под горизонтом никакая тяга не позволяет увеличить `r` (тест с тягой
  ~10⁶ g строго наружу).
* **Приближения:**
  * корабль — точечная мировая линия (его размер 74 м ≪ радиуса кривизны);
    конечный размер учитывается только через приливный тензор;
  * поворот корабля (РСУ) применяется в реальном времени, а не в ускоренном;
  * ускорение времени ограничивается так, чтобы на кадр приходилось не более
    96 подшагов (индикатор «огр. точностью»);
  * «Гипотетический двигатель» (до 2·10⁵ g с компенсацией инерции) —
    **нефизичное** допущение для облёта вблизи ЧД; реалистичный — 2 g / 8 g;
  * столкновений с газом диска нет: пролёт сквозь диск не оказывает
    механического воздействия.

## 9. Время

* `τ` — собственное время корабля (интегрируется).
* `t` удалённого наблюдателя — время Бойера–Линдквиста:
  `t_BL = t_KS − F(r)`, `dF/dr = 2Mr/Δ`. Расходится на горизонте; под
  горизонтом не определено (показывается «∞»).
* `dτ/dt = α/γ` — точное разложение на гравитационный фактор `α`
  (lapse ZAMO, `√(ΔΣ/A)`) и лоренц-фактор `γ` относительно ZAMO.
  Формула для неподвижного наблюдателя к свободно падающему кораблю не
  применяется.
* «До горизонта по τ» — баллистический прогноз (двигатели выключены):
  копия состояния интегрируется вперёд порциями в каждом кадре.
* Радиосвязь: отношение частот для сигнала, приходящего «сверху» вдоль
  главного изотропного направления (`ν/ν_∞ = l_μ u^μ`), и для радиального
  исходящего сигнала. **Приближение:** для Керра исходящий луч берётся
  радиальным в координатах КШ (точно для Шварцшильда). Темп речи ЦУПа
  меняется в это же число раз (ограничено 0.5–3 из-за синтезатора речи).

## 10. Приливы и разрушение

`src/physics/tidal.js`, `src/ship/structure.js`.

* Тензор Римана — центральные разности аналитических символов Кристоффеля
  (относительная точность ~10⁻⁸; тест по скаляру Кречмана).
* Приливный тензор в системе корабля `E_ab = R_{μανβ} e_a^μ u^α e_b^ν u^β`,
  девиация `d²ξ/dτ² = −E ξ`.
* **Приближения модели конструкции:** корпус — однородная балка длины
  `L = 74 м` с эффективной плотностью нагруженных узлов 2000 кг/м³;
  напряжение `σ = ρλL²/8` + нагрузка от тяги `ρaL/2`; пределы текучести и
  прочности как у титановых сплавов (880 / 1050 МПа); системы отказывают при
  заданных долях предела прочности; экипаж — по перепаду ускорений на 1.8 м
  и перегрузке. Пластическая деформация схематична; на внешней модели она
  показана **усиленной ×40**.
* Разрушение определяется только вычисленной нагрузкой. Кадр обрывается на
  подшаге, где достигнут следующий порог, поэтому событие фиксируется на
  правильном радиусе и при ускорении времени. Результаты:
  * Sgr A*: на горизонте перепад ускорений ~10⁻⁴ g по длине корабля;
    гибель экипажа при r ≈ 0.04M, разрушение корпуса при r ≈ 0.02M — глубоко
    под горизонтом, за доли секунды до r = 0;
  * 10 M☉: разрушение при r ≈ 100M — задолго до горизонта.

## 11. Граница применимости

* Шварцшильд: симуляция завершается при `r < 0.004M` — кривизна
  (`K = 48M²/r⁶`) неограниченно растёт, классическая ОТО перестаёт быть
  надёжной, а природа сингулярности не известна. Вид сингулярности не
  выдумывается.
* Керр: симуляция завершается у внутреннего горизонта Коши
  `r₋ + 0.04(r₊ − r₋)` — решение Керра там неустойчиво (инфляция массы,
  Poisson & Israel 1990).

## 12. Проверки (тесты)

`npm test` (node:test, 31 тест) и `npm run test:gpu` (рендер в Chromium):

* `g·g⁻¹ = δ`, аналитические производные метрики = конечные разности;
* горизонт: `g^μν ∂_μr ∂_νr = Δ/Σ`, обращается в ноль при `r = r₊, r₋`;
* ISCO, фотонные орбиты, КПД аккреции — известные значения;
* наблюдатели нормированы; ZAMO имеет `L = 0`, «дождевой» — `E = 1`, в том
  числе под горизонтом;
* скаляр Кречмана из численного тензора Римана = точная формула;
* круговая орбита: сохранение `r, E, L`, период;
* радиальное падение: `τ(r)` по формуле циклоиды через горизонт до `r → 0`;
* `dt_BL/dτ = 1/(1 − 2M/r)` для падения с бесконечности;
* геодезическая прецессия гироскопа;
* приливный тензор Шварцшильда `(−2M/r³, M/r³, M/r³)` снаружи и внутри
  горизонта; бесследовость тензора Керра;
* корабль под горизонтом не выходит наружу на полной тяге;
* фотоны: сохранение `H = 0` и константы Картера; критический угол тени
  `sin α = 3√3M√(1 − 2M/r)/r`; слабое отклонение `4M/b + 15πM²/(4b²)`;
  синее смещение звёзд `1/√(1 − 2M/r)`; асимптотическое направление;
* диск: формула Пейджа–Торна = численный интеграл; максимум потока при
  `r ≈ 9.55M`; `T ∝ r^{−3/4}`; КПД 5.7% и 32%;
* спектр: `∫B_λ dλ = σT⁴/π`, белая точка D65, предел Рэлея–Джинса;
* интеграция: Sgr A* — горизонт пройден целым, разрушение под горизонтом;
  10 M☉ — разрушение при r ≈ 102M; конец модели у горизонта Коши;
* **GPU:** размер и асимметрия тени на отрендеренном кадре совпадают с точной
  формулой и с CPU-интегратором в пределах пикселя (Шварцшильд и Керр).
