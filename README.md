# Горизонт событий — симулятор полёта к чёрной дыре

Интерактивная 3D-симуляция в реальном времени: вы в кабине исследовательского
корабля у сверхмассивной чёрной дыры массой 4·10⁶ M☉ (как Sagittarius A*).
Изображение — **трассировка световых лучей в метрике Керра на GPU** (не
текстура и не «чёрная сфера»), движение корабля — **уравнения ОТО** с тягой
двигателей и переносом гироскопов. Можно облететь ЧД, исследовать диск,
пересечь горизонт событий и продолжить падение до границы применимости
модели.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

Нужен браузер с WebGL 2 (Chrome, Edge, Firefox, Safari 15+). Для 60 FPS на
High — дискретная видеокарта; на слабых устройствах выберите Low (есть
динамическое разрешение).

Сборка и предпросмотр: `npm run build && npm run preview`.
Деплой на Vercel: `vercel.json` уже настроен (Vite, папка `dist`).

## Режимы

| режим | что даёт |
|---|---|
| Исследование | свободный полёт: тяга, ориентация, ускорение времени |
| Свободное падение | двигатели отключены, строго геодезическая траектория |
| Научная лаборатория | масса, вращение, диск, начальные условия; камера-зонд |
| Кинематографический | максимальное качество, плавная камера, минимум интерфейса |

## Управление

| клавиши | действие |
|---|---|
| W / S, A / D, Space / Ctrl | тяга вперёд/назад, вбок, вверх/вниз |
| Shift | форсаж |
| мышь | обзор (клик по изображению — захват указателя) |
| ↑ ↓ ← →, Q / E | тангаж, рысканье, крен корабля |
| ПКМ или V | развернуть корабль туда, куда смотрите |
| . / , (или ] / [) | ускорение / замедление времени |
| F / C | внешняя камера / свободная камера-зонд |
| T | двигатели вкл/выкл |
| B / X / G | диапазон (видимый/ИК/научный) / экспозиция / сетка неба |
| Tab | научная лаборатория |
| H / P / R | скрыть интерфейс / пауза / перезапуск |
| \` | качество Low → Ultra |
| M / F1 | звук / справка |

На телефоне: левый джойстик — тяга, правый — ориентация, перетаскивание по
экрану — обзор, кнопки — вверх/вниз, крен, форсаж, камеры, время, меню.

## Что моделируется

* Метрика Шварцшильда (a = 0) и Керра (a до 0.998) в координатах
  Керра–Шилда, регулярных на горизонте.
* Гравитационное линзирование, тень, фотонное кольцо, многократные
  изображения, искривлённый образ диска над и под тенью — следствия
  трассировки, а не наложенные эффекты.
* Гравитационное красное смещение, эффект Доплера, аберрация и
  релятивистское усиление яркости — через точное преобразование
  чернотельного спектра `T → g·T`.
* Диск Новикова–Торна: температура из массы и темпа аккреции; объёмная
  турбулентная структура; видимый цвет зависит от параметров и диапазона.
* Корабль: геодезическая с тягой, гироскопы по Ферми–Уокеру, приливный
  тензор Римана в системе корабля, напряжения корпуса, отказы систем,
  экипаж, разрушение — по вычисленной нагрузке.
* Часы: собственное время корабля, время удалённого наблюдателя,
  гравитационный и кинематический факторы, баллистическое время до горизонта.
* Под горизонтом выйти наружу невозможно; симуляция завершается при r → 0
  (Шварцшильд) или у горизонта Коши (Керр) с объяснением.
* Звук только внутри корабля; в вакууме тишина.

Все формулы, численные методы и **полный список приближений** —
в [`docs/PHYSICS.md`](docs/PHYSICS.md); устройство кода —
в [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).
