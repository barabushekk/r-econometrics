# Эконометрика в R — интерактивный путеводитель

Пошаговый курс для занятий по эконометрике: от установки RStudio до `lm()` и интерпретации `summary()`.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте адрес из терминала (обычно http://localhost:5173).

## Деплой на Vercel

### Вариант 1: через сайт

1. Загрузите репозиторий на GitHub / GitLab / Bitbucket.
2. Зайдите на [vercel.com](https://vercel.com) → **Add New Project**.
3. Импортируйте репозиторий. Vercel определит **Vite** автоматически.
4. Параметры сборки (если спросят):
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
5. Нажмите **Deploy**.

Файл `vercel.json` в корне уже настроен: SPA-маршрутизация и папка `dist`.

### Вариант 2: через CLI

```bash
npm i -g vercel
vercel login
vercel
```

Для продакшена:

```bash
vercel --prod
```

## Сборка вручную

```bash
npm run build
npm run preview
```

## Использование на занятиях

- Рекомендуется проектор + RStudio у студентов параллельно.
- Прогресс хранится в браузере (`localStorage`); для сброса — «Сбросить прогресс» в меню.
- Печать урока: кнопка «Печать» в шапке.

## Структура проекта

| Путь | Назначение |
|------|------------|
| `src/course.js` | Тексты уроков и шаги |
| `src/main.js` | Интерфейс приложения |
